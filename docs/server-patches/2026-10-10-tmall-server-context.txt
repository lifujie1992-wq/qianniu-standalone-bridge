天猫会话提炼改造（仅联想官方旗舰店）

客户端采集原始消息、原始时间及可观察的发送者/接收者身份。
历史缓存保留为上下文，不增加历史 SDK 查询或轮询频率，仍使用现有去重。
大脑集中解释身份、区分用户/客服/系统事件，以原始时间构建独立会话视图。
原始角色和正文保留用于复盘；上下文消息不作为新的自动发送触发。

转接先承接。当有效历史补传到达后，大脑在现有实时窗口内继续处理原问题。
手动暂停、已有真人答复、用户新问题、过期转接均阻止历史续答。
续答绑定实时转接父消息；首响应不再被误认为已完整回答。
客户端最后发送检查也使用实际发送者证据，防止大脑确认买家后被旧 unknown 标记拦截。
此检查只构建私有视图，保持原始上报记录；不确定身份、真人发送和新买家消息仍有保护。
队列释放后再次检查，避免刷新请求被首响应任务合并而丢失。

业务知识库、话术及意图规则沿用现有配置；本次不宣称解决全部业务理解问题。
旧客户端兼容后端，但服务器无法恢复客户端从未采集/上传的历史。
完整身份原始字段需使用本次客户端源码构建。应用版本号未修改，无 EXE。
PDD 入库调用、上下文顺序、发送判断保留原有行为，有回归覆盖。

验证：后端 744 passed，2 skipped（无独立 PostgreSQL 测试库），2 deselected
（已在未修改基线复现的既有失败：transfer_summary 与 sticky_handoff 断言）。
含 30 项新测试，覆盖真实入库→生成→发送链路、原始时间还原、队列竞态与重试，以及异常时间/时间单位兼容。
发送传输在回放中替换为测试桩，没有向真实客户发测试消息。
客户端 Python 天猫测试 107 passed，浏览器契约 29 passed。
尚未验证 Windows 千牛真实界面、CPU、延迟和实际发送成功率。

此 patch 用于审查后端变更；针对当前生产源码基线生成，并非全新后端仓库。
不要在不同后端基线上盲目应用。部署前先检查 git apply --check 与基线哈希。
