# 千牛 9.98.49N 兼容适配（助手 1.6.21）

## 适配内容

新版官方签名 AppBiz.dll 的 SizeOfImage 为 `0x2039000`，SHA-256 为
`71bb2b507ff3e646c14e41c15679e464752b8c93aa07c719a817b852fd5bc5bb`。
新增独立配置，同时保留已有版本配置，不把未识别的新版本当作已兼容。

| 接口 | RVA |
| --- | --- |
| serviceVtable | 0x19b1788 |
| secondaryVtable1 / secondaryVtable2 | 0x19b18f0 / 0x19b1900 |
| GetNewMsg / OnMessageArrive | 0xa81760 / 0xa85080 |
| serviceSendText | 0xa8d700 |
| messageBizVtable / messageBizSendText | 0x19af808 / 0xa6e800 |

上述地址由旧版函数锚点、虚表内容和相对布局交叉核对；发送服务函数锚点
未命中时，通过已确认虚表的 `+0x90` 槽获取，再反汇编确认直接调用
`messageBizSendText`。不能用低可信锚点或固定增量猜地址。

新旧版接收消息步长均为 584 字节，发送对象成员位置仍为 `+0x578`，
回调管理成员仍为 `+0x38`。原生发送辅助 DLL 同步增加新版配置及无副作用的
`appbiz_adapter_profile_supported_v1` 检查；新版脚本遇到旧 DLL 会明确拒绝，
不把脚本更新成功当作发送兼容成功。

- 新增 5 项配置一致性、实际 PE 虚表、旧 DLL 拒绝和辅助 DLL 布局检查。
- 完整隔离回归 415 项：414 通过、1 项因源码不含打包运行库而跳过。
- 离线检查不启动或重放真实消息，不调用发送接口。
- 本机已实际切换到 9.98.49N，逐项校验进程内函数/虚表及适配 DLL 导出。
  原生接收已就绪，大脑连接在线，当前会话昵称映射完整；可以读取原生历史和

## 连续点击跳转

浮窗原逻辑在有跳转进行时直接丢弃下一次点击，但会先更新选中会话，造成
浮窗目标和千牛实际打开目标不同。本版串行执行原生请求，保留等待中的最后
一次点击，旧请求的成功或失败均不能覆盖新目标提示。会话消息响应也检查
目标和请求序号，避免快速切换后的旧聊天内容覆盖当前会话。

原生跳转确认必须来自命令发出之后、同一进程与账号的会话选择通知，并核对
完整 ccode。历史缓存中的选中状态不能确认本次跳转；取消选择会清掉旧目标。
没有新回执时保持“尚未确认”，不报虚假的成功。

新增 Node 执行真实页面函数的异步竞态测试，覆盖连续点击、旧请求失败、最新
请求失败、旧消息响应晚到和消息加载延迟；原生测试覆盖旧缓存、精确新回执、
错误目标及取消选择。

## 已有昵称的刷新

新版千牛有时先给出登录名，联系人信息就绪后才给出实际昵称。原补查只处理
空昵称，导致非空旧缓存长期不更新。本版跟踪经过账号、完整 ccode 和买家
身份校验的原生昵称变化，通过既有 `nickname_update` 通道刷新已知会话。
按原生日志时间拒绝旧记录覆盖新记录；正常消息的正文、ID 和时间保持原样。
重复轮询不重复补传，瞬时入库失败保留更新并重试，未知联系人不会新建接待会话。
新增 7 项可执行回归覆盖上述场景。

显示昵称与 WWCmd 登录地址分开处理：跳转优先读取该账号、完整 ccode 绑定的
原始入站消息昵称，避免把联系人更新后的显示别名直接当作登录名。
历史快照、客服消息及昵称更新事件不参与选择跳转地址，最终仍以新的原生
完整会话 ID 回执验收。另有 3 项回归覆盖地址保留、账号隔离和地址来源过滤。

客户端安装包携带完整 9.98.49N 运行库和对应辅助 DLL，记录源提交和文件校验值。
构建前清理并重新注入打包配置，检查包内不含本机令牌、聊天记录或登录状态。
