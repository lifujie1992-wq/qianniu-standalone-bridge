## 适配内容

新版官方签名 AppBiz.dll 的 SizeOfImage 为 `0x2039000`，SHA-256 为
`71bb2b507ff3e646c14e41c15679e464752b8c93aa07c719a817b852fd5bc5bb`。
新增独立配置，同时保留已有版本配置，不把未识别的新版本当作已兼容。

| 接口 | RVA |
| --- | --- |
| serviceVtable | 0x19b1788 |
| secondaryVtable1 / secondaryVtable2 | 0x19b18f0 / 0x19b1900 |
| GetNewMsg / OnMessageArrive | 0xa81760 / 0xa85080 |
| serviceSendText | 0xa8d700 |
| messageBizVtable / messageBizSendText | 0x19af808 / 0xa6e800 |

上述地址由旧版函数锚点、虚表内容和相对布局交叉核对；发送服务函数锚点
未命中时，通过已确认虚表的 `+0x90` 槽获取，再反汇编确认直接调用
`messageBizSendText`。不能用低可信锚点或固定增量猜地址。

新旧版接收消息步长均为 584 字节，发送对象成员位置仍为 `+0x578`，
回调管理成员仍为 `+0x38`。原生发送辅助 DLL 同步增加新版配置及无副作用的
`appbiz_adapter_profile_supported_v1` 检查；新版脚本遇到旧 DLL 会明确拒绝，
不把脚本更新成功当作发送兼容成功。
