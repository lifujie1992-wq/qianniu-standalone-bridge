# 1.6.16：千牛 9.97.86N 兼容和跨机器昵称诊断

## 故障证据

本机从 9.97.81N 自动更新为 9.97.86N，AppBiz SizeOfImage 为 0x1f31000。
1.6.15 未包含该版本，原生接收和发送均未就绪，而大脑连接仍在线。
初始化脚本在导出 status 前退出，最终错误变成 unable to find method status，
掩盖了实际的客户端不兼容原因。

## 兼容处理

新增 9.97.86N 的 AppBiz hook 和 C++ 发送适配器配置。以已知 9.97.81N
模块进行函数锚点和虚表内容对照；GetNewMsg / OnMessageArrive / MessageBiz
发送入口各有多个唯一锚点，四个虚表内容及相对布局一致。SendText 的单个
锚点为误匹配，实际入口从已确认虚表 +0x90 得出 0xa84b40。四个函数均位于
PE 异常表函数起点，函数长度与上一版本相同。映射工具拒绝少于 5 票的锚点。

模块 SHA256：ed3adca4673e130d2e25f91e95108f93f61814af72ab9fd91fbafedce9330c43。
新配置仍执行已有的可执行地址、虚表槽位和对象结构断言。未知版本在注入前
显示明确错误。页面消息接收状态以真正的 SDK hook 或原生接收能力为准。

## 昵称处理

旧版昵称补全主要依赖标准位置的 app.log，因此仅本机正常不能证明其他
机器正常。新增从运行中 AliRender 的 --log_file 参数识别日志目录，也读取
千牛配置和注册表中明确的数据/日志路径，保留标准目录和手工配置兜底。
兼容 UTF-8/GB18030 及单账号或重复账号日志头；仍严格核对完整会话 ID 和
买家身份，不从别的买家或客服昵称推断。SDK 返回 UID 的带 .1 / 不带 .1
两种格式做等值归一化，不放宽不同 UID 的匹配。

状态新增目录来源、已读事件数、昵称命中数、解码失败数。设置页可导出诊断
JSON，包含构建来源、原生通道能力、日志发现和昵称缺失计数，不包含令牌、
聊天正文或买家名单。用于确认其他机器是否装了相同构建及其实际故障点。

未取得其他电脑的日志与诊断前，不能断言所有跨机器昵称问题已解决。
未新增或运行自动化测试，未主动发送客户消息。完成源码语法检查和构建；
原生真实发送仍需用户的实际接待观察。
